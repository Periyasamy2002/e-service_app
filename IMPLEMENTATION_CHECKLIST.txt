COMMON TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Styles not loading
Solution:
  □ Run: python manage.py collectstatic --clear
  □ Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R)
  □ Check: STATIC_URL in settings.py
  □ Verify: CSS file path correct

Problem: JavaScript errors
Solution:
  □ Check: Browser console for errors
  □ Verify: Script tag placed before </body>
  □ Check: professional-interactions.js file exists
  □ Test: Load JS file directly in browser

Problem: Images not showing
Solution:
  □ Check: Internet connection (Unsplash CDN)
  □ Verify: Image URLs correct
  □ Check: Browser console for 404 errors
  □ Use: Fallback images if needed

Problem: Responsive not working
Solution:
  □ Check: Meta viewport tag present
  □ Verify: media queries in CSS
  □ Test: Different breakpoints
  □ Check: z-index conflicts

Problem: Animations stuttering
Solution:
  □ Check: GPU acceleration enabled
  □ Reduce: Animation count
  □ Increase: Animation duration
  □ Check: Browser hardware acceleration
